# Contributing to 38Games projects

Thank you for taking the time to improve a 38Games project.

## Before starting

1. Search existing issues and pull requests for similar work.
2. Open an issue before starting a large change.
3. Keep changes focused on one problem or feature.

## Pull requests

- Use a clear title and explain why the change is needed.
- Test the affected behavior before requesting review.
- Include screenshots or recordings for visual changes.
- Never commit credentials, API keys, private customer data or generated build folders.
- Follow the conventions already used by the project.

Project-specific instructions take precedence when a repository contains its own `CONTRIBUTING.md`.
