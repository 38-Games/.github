# 38Games GitHub configuration

This repository contains the public organization profile and shared community files for 38Games.

## Included

- Organization profile in `profile/README.md`
- Bug report and feature request forms
- Pull request template
- Contribution, security, support, and conduct guidelines
- Reusable Unity project-check workflow template

The content of `profile/README.md` is displayed on the public 38Games organization overview page.
